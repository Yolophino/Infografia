Capa de Transporte

El enlace entre las aplicaciones y la red que garantiza una comunicación eficiente y confiable

¿Qué hace la capa de transporte?

La capa de transporte coordina la comunicación entre las aplicaciones que se ejecutan en dispositivos conectados. Organiza el flujo de datos, identifica a qué aplicación pertenece cada información y determina el nivel de confiabilidad necesario según el servicio que se esté utilizando.

Funciones principales

Puertos y Sockets

Identifican la aplicación correcta que debe recibir los datos.

Multiplexación

Reúne datos de varias aplicaciones para compartir un mismo canal.

Demultiplexación

Entrega cada segmento a la aplicación correspondiente.

Segmentación

Divide grandes cantidades de información en segmentos más pequeños.

Encapsulamiento

Agrega información de control antes de transmitir los datos.

Control de errores

Facilita recuperar únicamente los segmentos perdidos.

Comunicación simultánea

Permite que varias aplicaciones utilicen la misma conexión.

Entrega ordenada

Garantiza que cada aplicación reciba únicamente su información.

TCP (Transmission Control Protocol)

Prioriza la confiabilidad para asegurar que la información llegue completa, sin errores y respetando el orden original de transmisión.

ACK

Confirma la recepción correcta de los segmentos.

Retransmisión

Reenvía datos cuando detecta pérdidas.

Control de Flujo

Utiliza la ventana deslizante para evitar saturar al receptor.

Control de Congestión

Regula el tráfico para mantener estable la red.

Entrega Ordenada

Reconstruye correctamente la secuencia original.

Aplicaciones

Web, banca, correo electrónico y transferencia de archivos.

UDP (User Datagram Protocol)

Reduce los mecanismos de control para ofrecer transmisiones más rápidas, priorizando la velocidad sobre la confiabilidad.

Sin conexión

No establece sesiones antes de transmitir.

Sin ACK

No espera confirmaciones de recepción.

Mayor velocidad

Reduce la latencia durante la comunicación.

Streaming

Ideal para video y audio en tiempo real.

Videollamadas

Prefiere continuidad antes que retransmitir paquetes.

Videojuegos

Minimiza retrasos durante la interacción.

Administración de Sesiones

Three-Way Handshake

Establece la conexión entre los dispositivos.

Estados TCP

Administran el ciclo de vida de la conexión.

Terminación

Finaliza la sesión de forma controlada.

Timers

Detectan retrasos y activan recuperaciones.

Supervisión

Garantiza estabilidad durante toda la comunicación.

TCP vs UDP

TCP

  • Orientado a conexión.
  • Alta confiabilidad.
  • Control de errores.
  • Control de flujo y congestión.
  • Mayor precisión.

UDP

  • Sin conexión.
  • Mayor velocidad.
  • Sin retransmisiones.
  • Baja latencia.
  • Ideal para tiempo real.

Idea principal

La capa de transporte permite que múltiples aplicaciones compartan una misma conexión de red de manera organizada. TCP proporciona confiabilidad mediante control de errores y sesiones, mientras que UDP ofrece rapidez para aplicaciones en tiempo real. Ambos protocolos responden a necesidades diferentes y son esenciales para el funcionamiento de Internet.
